# JTTY presentation update

The reproducible UI overlay is `scripts/customize-jtty-ui.py`, invoked by `prepare-wsjtx-jtty.py`. The gray stylesheet is `native/qt-ui/gray.qss`.

Operational branding now identifies JTTY Workbench in the title, menus, splash, settings, tooltips, and help. The original copyright list, GPL notice and source-project attribution remain in the About/legal notices. The startup splash uses a gray background and the JTTY icon instead of the upstream artwork.

Removed visible access to unavailable multimode decoder options, astronomy/echo/fast graph windows, Fox/Hound tools, unrelated guides, and frequency/phase measurement tools. Settings hide the generic FT8 macro tab, irrelevant filters, VHF/EME options, JT65 parameters, tone spacing and special operating mode selectors. JTTY's editable F1–F8 macro fields, frequency selector/band buttons, station/radio/audio setup, logging and waterfall controls remain available.

Message panels use light gray against a medium gray surface and are labeled Received messages and Conversation on selected frequency. The typing field includes an Enter-to-send prompt. The receive-period progress display is hidden while listening; transmit status remains available.

Verification: full Qt app rebuilt; isolated startup/mode restriction test passed; upstream JTTY live audio fixture test passed (20.46 seconds). An actual offscreen widget rendering was visually inspected at `build/jtty-gray-preview.png`. Recreating the source from the pinned submodule reproduced the modified source files exactly. No physical radio success is claimed by these presentation checks.

Updated bundle: `build/JTTY Workbench WSJTX.app`. Quit the running instance and reopen this bundle to load the new interface.
